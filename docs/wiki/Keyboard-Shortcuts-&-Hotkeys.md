# Keyboard Shortcuts & Hotkeys

NewsAlerts is built for rapid keyboard-driven workflow. Use these hotkeys to navigate the terminal without leaving your keyboard, and customize them to your preferred trading style.

---

## ⚡ Default Keyboard Shortcuts

| Shortcut | Action | Description |
| :---: | :--- | :--- |
| **`M`** | **Master Mute** | Instantly toggles audio bell chimes and Telegram alert dispatching. |
| **`T`** | **Pop-Out Tape** | Opens the detached, floating running tape window. |
| **`Space`** | **Pause / Resume** | Pauses or resumes real-time tape and screener stream updates. |
| **`S`** | **Open Settings** | Launches the modal settings window for feeds, audio, and strategies. |
| **`R`** | **Force Refresh** | Triggers an immediate re-scan and news headline refresh. |
| **`Esc`** | **Close Modal** | Closes any open dialog (Settings, Story View, About). |
| **`1` – `5`** | **Filter Presets** | Quickly switches between predefined momentum screener presets. |
| **`Up` / `Down`** | **Row Selection** | Move active selection up or down across screener rows. |
| **`Enter`** | **Focus Story** | Loads the latest catalyst story for the selected ticker. |

---

## 🛠️ Customizing Shortcuts in Settings

Starting in **v2.5.0**, hotkeys are fully customizable to user preference:

1. Open **Settings** (press `S` or click the gear icon in the topbar).
2. Click the **Hotkeys** tab.
3. Click any shortcut key badge. The badge will glow green with `Press key...`.
4. Press the key you wish to assign (letters, numbers, `Space`, `Enter`, `Escape`, etc.).
5. The shortcut is instantly bound and a confirmation toast appears.
6. Click **Save Settings** in the modal footer to persist your bindings to `config.json`.
7. Need to revert? Click **↺ Reset Defaults** at the top of the tab anytime.

> [!NOTE]
> All hotkeys automatically bypass execution when your cursor is focused inside an input, select, or search field to avoid interfering with typing. Press `Esc` at any time to blur active input focus or dismiss open dialogs.
