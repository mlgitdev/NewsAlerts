# NewsAlerts v2.10.0 — Release Notes

**Release Date:** October 2026  
**Type:** Minor Release (`MINOR` — Broker Closing-Only & Banned Stock Filter Engine)  
**Single Source of Truth:** `VERSION` (`2.10.0`)

---

## 🚀 Overview

NewsAlerts **v2.10.0** introduces the **Broker Closing-Only & Banned Stock Filter Engine**, specifically addressing a critical pain point for day traders using Interactive Brokers (IBKR) and other active retail/institutional brokerages: un-tradeable stocks placed into "closing-only" or margin-restricted status (such as `YMAT` on `NASDAQ.SCM`).

Because broker risk departments restrict high-risk micro-caps internally without broadcasting public market feed flags, traders previously suffered rejected orders and wasted attention. Version 2.10.0 gives traders total control with an instant **Top Banner Toggle Switch**, **1-Click 🚫 Symbol Blacklisting**, and a **Dedicated Settings Manager**.

---

## 🛠️ Key Additions & Architectural Enhancements

### 1. Interactive Topbar Filter Toggle (`[🚫 Banned: ON / OFF]`)
- Docked directly in the main navigation banner alongside the session selectors.
- Features vibrant institutional color feedback:
  - **Inactive (`OFF`)**: Clean dark badge (`Banned: OFF`).
  - **Active (`ON (N)`)**: Vibrant red/amber institutional badge (`Banned: ON (N)`) displaying the active banned count with subtle glowing border.
- Instantly hides all banned symbols across both the **Momentum Screener grid** and the **Running Tape stream** without page reload.
- Suppresses audible chimes and Telegram notifications for all banned tickers while the filter is active.

### 2. 1-Click Symbol Blacklisting (`🚫`)
- Added a compact `🚫` button directly adjacent to ticker symbols in:
  1. **Screener Rows**: Click 🚫 next to any symbol to ban it immediately.
  2. **Running Tape Events**: Click 🚫 on any momentum card to ban the symbol directly from the tape.
  3. **News Headline Banner**: Click 🚫 on the active inspected ticker in the catalyst pane header.
  4. **Popout Tape Window**: Works seamlessly in detached multi-monitor floating tape windows.
- Provides immediate visual toast confirmation. When the filter is active, banned symbols immediately disappear from active tables.

### 3. Settings Banned Stocks Manager (`Settings → 🚫 Banned Stocks`)
- Dedicated settings tab allowing traders to:
  - Toggle global filter activation state.
  - View all banned symbols as interactive chips with one-click `✕` removal buttons.
  - Manually add tickers via text input (with automatic uppercase sanitization and Enter key support).
  - Clear all banned tickers with a single click.
  - Shows real-time symbol count badges.
- Persists state in `%APPDATA%\NewsAlerts\config.json` under `banned_symbols` (pre-seeded with `YMAT`) and `filter_banned`.
