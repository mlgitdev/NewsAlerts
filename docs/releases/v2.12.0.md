# NewsAlerts v2.12.0 — Release Notes

**Release Date:** October 2026  
**Type:** Minor Release (`MINOR` — Dual Independent In-App Audio & Telegram Topbar Alert Controls)  
**Single Source of Truth:** `VERSION` (`2.12.0`)

---

## 🚀 Overview

NewsAlerts **v2.12.0** introduces a **Dual Independent Alert Controls Architecture** with dedicated topbar toggles:
1. **Dedicated Topbar Telegram Alert Toggle (`#btn-telegram`)**: Adds an institutional topbar icon combining the iconic Telegram paper airplane with an alert bell badge. Traders can now mute or resume Telegram mobile & desktop push notifications with a single click directly from the header without opening Settings.
2. **Decoupled In-App Audio Bell (`#btn-mute`)**: Decouples the primary audio bell toggle so it strictly governs local PC waveform audio alert chimes (`alerts.mute`). When active momentum day traders are operating directly in front of the workstation, they can silence noisy Telegram phone alerts with 1 click while preserving essential zero-latency PC audio chimes.
3. **Synchronized State & Hotkeys**: Bidirectional synchronization connects the topbar Telegram button directly with Settings &rarr; Alerts &rarr; *Enable Telegram Alerts*. Supports customizable hotkeys for both local audio mute and Telegram push notification toggling.

---

## 🌟 Key Changes & Improvements

### 1. Dedicated Topbar Telegram Alerts Toggle (Issue #65)
- Added `#btn-telegram` immediately adjacent to the audio bell in the topbar header.
- **Custom Vector Icon**: Custom high-DPI SVG combining the Telegram paper airplane pointing northeast with a docked alert bell badge.
- **Institutional Status Feedback**:
  - **Active State**: Rendered in Telegram Blue (`#29b6f6`) with soft border glow and interactive hover states.
  - **Paused State**: Switches to a slashed vector strike (`tgBellOff`) with red-tinted background (`rgba(246, 70, 93, 0.14)`), red border (`#ff6b7e`), and pulsing alert warning glow (`pausePulse`).
- **One-Click Instant Execution**: Toggling updates `alerts.telegram_enabled` in real-time, persists to `config.json`, and reflects immediately across the terminal UI.

### 2. Fully Decoupled Alert Engine
- **In-App Audio Chimes**: Governed exclusively by `alerts.mute`. Muting local sound chimes no longer suppresses Telegram push alerts if Telegram is enabled.
- **Telegram Push Notifications**: Governed exclusively by `alerts.telegram_enabled` (and tape-specific filters/cooldowns). Silencing Telegram at your desk leaves local workstation audio bells fully functional.
- Updated backend dispatch in `app/screener.py`, `app/tape.py`, `app/api.py`, and `app/main.py`.

### 3. Keyboard Shortcut & Hotkey Integration
- Default `m` hotkey preserved for rapid In-App Audio Mute.
- Added `toggle_telegram` hotkey action in keyboard shortcuts configuration, allowing traders to map any preferred key combination to instant Telegram toggling.

### 4. Startup Alert State Synchronization (Bug Fix)
- Resolved an issue where closing the app with Alerts muted resulted in the topbar alert button displaying as active upon re-opening.
- Both `#btn-mute` and `#btn-telegram` now immediately synchronize their icons, titles, and `.paused` CSS classes against persisted configuration during `init()`.
