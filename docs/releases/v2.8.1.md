## 🚀 Overview

NewsAlerts `v2.8.1` resolves a critical UI freeze and cross-thread deadlock that occurred when saving settings after tuning audio chimes or reviewing configuration options. In addition, it optimizes configuration updates by eliminating redundant background network calls (re-authentication and 15MB bulk asset fetches) when credentials have not changed.

### 🛠️ Bug Fixes & Architectural Hardening

### 1. Eliminated Cross-Thread WinForms Deadlock (`set_on_top`)
- **Root Cause**: When clicking "Save Settings", `Settings.applyUi()` dispatched `POST /api/set_on_top`. In the backend WSGI worker thread, assigning `pywebview`'s `window.on_top` called `winforms.py:1006` (`i.TopMost = on_top`) off the main UI thread without proper message marshaling, freezing the COM / WinForms event loop and leaving the entire application unresponsive.
- **Resolution**:
  - In `app/api.py`, `set_on_top` now interacts directly with Win32 `user32.SetWindowPos` on Windows using the form's HWND (`HWND_TOPMOST` / `HWND_NOTOPMOST` with `SWP_NOMOVE | SWP_NOSIZE | SWP_NOACTIVATE`), which is completely thread-safe and non-blocking.
  - Caches `_on_top_state` to immediately short-circuit redundant calls.
  - In `web/js/settings.js`, `Settings._currentOnTop` caches the current window state and only dispatches `/api/set_on_top` when `always_on_top` has actually changed.

### 2. Guarded Against Redundant Network Operations on Settings Save
- **TradingView Session Guard (`tv_client.py`)**: `set_cookies()` now verifies whether `sessionid` and `sessionid_sign` have actually changed before clearing cookies and spawning a background auth verification HTTP request.
- **Alpaca Bulk Asset Sync Guard (`borrow.py`)**: `update_credentials()` now verifies whether `key_id`, `secret_key`, and `mode` have changed before spawning a new thread to download and process 14,000+ US equity records.
