## 🚀 Overview

NewsAlerts `v2.4.1` is a patch release addressing runtime UI asset serving, grid alignment in settings, brand header navigation, and social preview assets:

### 🐛 Bug Fixes & Improvements
1. **Settings Modal "About" Banner & Static Route Resolution**:
   - Fixed missing `@app.route("/img/<filepath:path>")` and static file handlers in the local Bottle server (`app/server.py`), restoring the hero banner image in the About tab.
   - Added regex static route and multi-directory resolution covering `web/`, `web/img/`, and `assets/`.
2. **Form Grid Alignment & Null Text Node Elimination**:
   - Fixed `Settings.field()` in `web/js/settings.js` where omitted help parameters returned `[label, input, null]`. Modern DOM `Element.append(null)` coerced `null` into literal text nodes that offset grid cells across rows.
   - Guarded `alpacaBanner` in the Borrow tab to only append when truthy.
3. **Interactive Topbar Brand Widget**:
   - Added `id="btn-brand-about"` with click and keyboard (`Enter`/`Space`) event listeners opening the About pane directly.
   - Enhanced CSS hover glow, active press states, and dynamic version tooltip.
4. **Social Media Preview Assets**:
   - Added official 1280×640 GitHub Social Media Preview Card (`assets/social_preview.png`) and automated generator script (`scripts/make_social_preview.py`).
5. **Pitch & Real-Time News Value Proposition**:
   - Updated documentation and specifications highlighting the zero-lag catalyst news wire advantage over retail charting delays.
