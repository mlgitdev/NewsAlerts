# NewsAlerts v2.6.0 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.6.0`  
**SemVer Specification:** `2.6.0` (Major: 2, Minor: 6, Patch: 0)  

---

## 🚀 Overview

NewsAlerts `v2.6.0` is a minor feature release introducing **Large-Cap & High-Float Momentum Squeeze Strategies**, high-velocity 5-minute surge detection (`Up 10% in 5min`), expanded universe boundaries, and server-side velocity detection (`change|5`) to eliminate tape blind spots for high-profile momentum runners like SMCI, NVDA, and TSLA.

### 🌟 Key Enhancements & Fixes

1. **Large-Cap & High-Float Momentum Strategies**:
   - Added **`Large Cap / High Float - Momentum Squeeze`** (`family: "large"`, `trigger: "squeeze"`, `float_min: 100M`, `up_pct: 5%`, `window_min: 5min`).
   - Added **`Large Cap / High Float - High Rel Vol - Price $20+`** (`family: "large"`, `trigger: "hod"`, `float_min: 100M`, `relvol_min: 2.0`, `price_min: $20`).
   - Added **`Squeeze Alert - Up 10% in 5min`** (`family: "squeeze"`, `trigger: "squeeze"`, `up_pct: 10%`, `window_min: 5min`) for ultra-high-velocity momentum spikes.
   - Institutional purple accent styling (`var(--accent-2)`: `#8b5cf6`) across tape rows and strategy filter pills.

2. **Server-Side Velocity (`change|5`) & Cold-Start Surge Capture**:
   - Integrated TradingView's server-side `change|5` and `change|15` columns into the active scanning engine (`app/sessions.py`).
   - Squeeze strategies now evaluate both rolling in-memory tick history and server-side 5-minute velocity, eliminating the previous 30-second cold-start delay when a runner suddenly enters the universe.
   - Detects newly entered universe runners whose session or postmarket change (`postmarket_change`) explodes on breaking earnings or catalyst releases (such as SMCI's +11% post-market surge).

3. **Expanded Tape Universe Boundaries**:
   - Increased default universe price ceiling from `$50` to `$500` and relaxed lower change threshold to `1.0%` with limit raised to `400` symbols.
   - Supports open-ended price ranges when `price_max` is cleared or set to 0 in Settings.

4. **Multi-OS Configuration Migration**:
   - Upgraded `_merge()` in `app/config.py` to seamlessly append new default strategies and enable them for existing installations without overwriting user customizations.
   - Added comprehensive unit test suite in `tests/test_tape.py` validating large-cap float thresholds, surge velocity triggers, and post-market alerts.
