# NewsAlerts v2.4.3 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.4.3`  
**SemVer Specification:** `2.4.3` (Major: 2, Minor: 4, Patch: 3)  

---

## 🚀 Overview

NewsAlerts `v2.4.3` is a patch release introducing robust cross-platform application data directory resolution across Windows, Linux, and macOS, supporting explicit custom directory overrides (`NEWSALERTS_DIR` / `NEWSALERTS_HOME`) and `$HOME/.newsalerts` dotfolder conventions, alongside automated directory and configuration provisioning on first launch.

### 🌟 New Features & Enhancements
1. **Multi-OS Application Data Directory Resolution (`APP_DIR`)**:
   - Added support for explicit environment overrides via `NEWSALERTS_DIR` or `NEWSALERTS_HOME` (e.g. `export NEWSALERTS_DIR=$HOME/.newsalerts`).
   - Added automated detection and preference for `$HOME/.newsalerts` across all operating systems.
   - Preserved institutional defaults: `%APPDATA%\NewsAlerts\` on Windows, `~/Library/Application Support/NewsAlerts/` on macOS, and `$XDG_CONFIG_HOME/NewsAlerts/` or `~/.config/NewsAlerts/` on Linux.
2. **Automated Directory & File Provisioning**:
   - `get_app_dir()` automatically invokes `mkdir(parents=True, exist_ok=True)` on startup.
   - `Config._load()` automatically generates and persists default `config.json` with institutional presets upon initial launch if missing.
   - Added `ensure_app_dir_initialized()` helper function.
3. **Comprehensive Specification & Documentation Updates**:
   - Updated [`docs/SPEC.md`](../SPEC.md), [`docs/DIRECTORIES.md`](../DIRECTORIES.md), and [`docs/CONFIGURATION.md`](../CONFIGURATION.md).
   - Updated wiki documentation in [`docs/wiki/Configuration-&-Secrets-Guide.md`](../wiki/Configuration-&-Secrets-Guide.md).
4. **Automated Unit Testing**:
   - Added [`tests/test_config.py`](../../tests/test_config.py) validating environment overrides, dotfolder detection, and configuration provisioning.
