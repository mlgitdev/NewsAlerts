# NewsAlerts v2.4.5 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.4.5`  
**SemVer Specification:** `2.4.5` (Major: 2, Minor: 4, Patch: 5)  

---

## 🚀 Overview

NewsAlerts `v2.4.5` is a patch release introducing the centralized **Single Source of Truth (SSOT)** versioning architecture. Application versioning is now governed exclusively by a root `VERSION` file, completely decoupling code and frontend interfaces from static version strings.

### 🌟 Fixes & Enhancements
1. **Root `VERSION` Single Source of Truth**:
   - Created the root [`VERSION`](../../VERSION) file containing the plain SemVer string (`2.4.5`).
   - All other files, packaging scripts, and test suites now derive their version dynamically from this single file.
2. **Dynamic Runtime Resolution (`app/version.py`)**:
   - Enhanced `app/version.py` with `_load_version()` to read `VERSION` directly at startup.
   - Fully compatible with PyInstaller standalone executables via `sys._MEIPASS / "VERSION"`.
   - `VERSION_INFO` tuple `(major, minor, patch)` and git tag representation `vX.Y.Z` are computed dynamically from the parsed SemVer object, eliminating redundant manual edits.
3. **Packaging Integration (`NewsAlerts.spec` & `build.ps1`)**:
   - Added `('VERSION', '.')` to PyInstaller datas in `NewsAlerts.spec` to guarantee bundle encapsulation.
   - Updated `build.ps1` to query the root `VERSION` file for build banners and artifact names.
4. **Decoupled Frontend Badges**:
   - Removed static hardcoded version strings from `web/index.html` and `web/tape.html`.
   - Brand headers, corner badges, and About modal metadata are populated dynamically at runtime from `App.api().get_state()`.
   - Removed hardcoded fallbacks from `web/js/app.js` and `web/js/settings.js`.
5. **Dynamic Test Assertions**:
   - Updated `tests/test_version.py` to assert dynamically against `__version__` and verify exact equality with the root `VERSION` file.
