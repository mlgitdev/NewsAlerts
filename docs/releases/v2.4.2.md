# NewsAlerts v2.4.2 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.4.2`  
**SemVer Specification:** `2.4.2` (Major: 2, Minor: 4, Patch: 2)  

---

## 🚀 Overview

NewsAlerts `v2.4.2` is a patch release introducing external project & wiki documentation links into the runtime About pane, updating the primary repository hero showcase with the 1280x640 institutional preview card, documenting the one-click TradingView chart launch button, and establishing the comprehensive GitHub Wiki documentation suite.

### 🌟 New Features & Enhancements
1. **About Pane Documentation & GitHub Links**:
   - Added direct, clickable links to the **GitHub Repository** (`https://github.com/mlgitdev/NewsAlerts`) and the **Documentation Wiki** (`https://github.com/mlgitdev/NewsAlerts/wiki`) within the Settings & About modal (`web/js/settings.js`).
   - Clicking opens the user's default browser directly with zero disruption to active market scanning.
2. **README Hero Banner & Social Preview Integration**:
   - Updated the primary `README.md` hero section to feature the official `assets/social_preview.png` institutional card.
   - Added interactive shields badge directing traders to the GitHub Wiki.
3. **One-Click TradingView Chart Popout Documentation**:
   - Fully documented the `#news-chart` button located in the news headline pane header.
   - Clarified sub-second workflow: clicking the chart icon immediately opens `https://www.tradingview.com/chart/?symbol=<TICKER>` in the browser with no manual symbol typing required.
4. **Comprehensive GitHub Wiki Documentation Suite (`docs/wiki/`)**:
   - Authored complete multi-page wiki suite: `Home.md`, `TradingView-Integration-&-Charts.md`, `Real-Time-Momentum-Screener.md`, `Running-Momentum-Tape.md`, `Multi-Strategy-Rules-Engine.md`, `Catalyst-News-Wire-&-Benzinga.md`, `Short-Borrow-Locates-(Alpaca-&-TradingView).md`, `Audio-Alerts-&-Volume-Controls.md`, `Telegram-Push-Notifications.md`, `Configuration-&-Secrets-Guide.md`, `Keyboard-Shortcuts-&-Hotkeys.md`, `Building-&-Packaging-From-Source.md`, `_Sidebar.md`, and `_Footer.md`.
   - Added `scripts/sync_wiki.py` to synchronize markdown pages to GitHub's wiki git backend.
