# NewsAlerts v2.4.4 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.4.4`  
**SemVer Specification:** `2.4.4` (Major: 2, Minor: 4, Patch: 4)  

---

## 🚀 Overview

NewsAlerts `v2.4.4` is a patch release fixing and activating full terminal-wide keyboard shortcuts and hotkeys (`M`, `T`, `Space`, `S`, `R`, `Esc`, `1`–`5`, `Up`/`Down`, and `Enter`), with toast feedback and input element guards across main and detached tape windows.

### 🌟 Fixes & Enhancements
1. **Global Keyboard Shortcuts & Hotkeys Coordinator**:
   - Implemented centralized keyboard event listener in [`web/js/app.js`](../../web/js/app.js) activating all documented institutional hotkeys.
   - **`M` / `m` (Master Mute)**: Instantly toggles alert audio chimes and Telegram alerts with visual state and toast feedback.
   - **`T` / `t` (Pop-Out Tape)**: Launches the floating, borderless detached tape window.
   - **`Space` (Pause / Resume)**: Toggles tape momentum stream updates with visual toast indication (supported in both main terminal and popout tape).
   - **`S` / `s` (Settings Modal)**: Toggles the modal settings window for feeds, audio, and strategies.
   - **`R` / `r` (Force Refresh)**: Triggers an immediate re-scan and news headline refresh via new `/api/refresh` backend endpoint.
   - **`Esc` (Close Modal)**: Closes open dialogs (Settings, Symbol Alert Drawer, story views) and blurs focused inputs.
   - **`1` – `5` (Filter Presets)**: Instantly switches between screener preset tabs with toast confirmation.
   - **`Enter` (Focus Story)**: Automatically expands and focuses the latest catalyst news story for the selected symbol.
   - **`Up` / `Down` (Row Navigation)**: Smooth navigation across screener rows with auto-selection.
2. **Input Element Protection**:
   - Hotkeys automatically bypass execution when the active element is an `<input>`, `<select>`, `<textarea>`, or content-editable field (except `Escape` which blurs).
   - Modifier keys (`Ctrl`, `Alt`, `Meta`) are preserved for native OS combinations (e.g. `Ctrl+C`, `Ctrl+V`, `Ctrl+R`).
3. **Backend API Endpoint**:
   - Added `refresh()` method to [`app/api.py`](../../app/api.py) and `/api/refresh` route in [`app/server.py`](../../app/server.py) to trigger immediate scanner pokes.
4. **SemVer Version Bump**:
   - Application version bumped to `2.4.4` across all runtime layers, tests, and web interfaces.
