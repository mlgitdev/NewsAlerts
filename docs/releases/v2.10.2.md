# NewsAlerts v2.10.2 — Release Notes

**Release Date:** October 2026  
**Type:** Patch Release (`PATCH` — Topbar Banned Count Sync & Terminal Showcase Media)  
**Single Source of Truth:** `VERSION` (`2.10.2`)

---

## 🚀 Overview

NewsAlerts **v2.10.2** fixes a client-side badge desynchronization bug in the top banner **`[🚫 Banned: ON (N)]`** toggle pill and updates the flagship terminal showcase assets across the documentation, README, and GitHub Wiki with live institutional captures.

---

## 🛠️ Key Bug Fixes & Enhancements

### 1. Topbar Banned Filter Count Synchronization (Issue #48)
- **Settings Save Reaction**:
  - Exposed `App.updateFilterBannedButton()` globally.
  - Wired `#settings-save.onclick` to automatically invoke `App.updateFilterBannedButton()` upon saving configuration changes.
  - When new symbols (e.g. `CLIK`) are added to or removed from the Banned Stocks list in Settings, the topbar filter badge immediately reflects the exact total count (e.g. `Banned: ON (2)`) without requiring manual toggling OFF and ON again.
- **Resilient Symbol Matching**:
  - Standardized symbol qualification across Screener (`web/js/screener.js`), Tape (`web/js/tape.js`), and News wire (`web/js/news.js`) to match against both bare ticker symbols (e.g. `CLIK`) and exchange-qualified formats (e.g. `NASDAQ:CLIK`).

### 2. High-Resolution Terminal & Settings Showcase Media (Issue #48)
- **Flagship Terminal Screenshot (`docs/img/terminal.png`)**:
  - Updated to live institutional terminal capture featuring the active `[🚫 Banned: ON]` pill, 1-click blacklisting buttons, live momentum prints, and Screener grid.
  - Integrated into `README.md`, `docs/wiki/Home.md`, and `docs/wiki/Catalyst-News-Wire-&-Benzinga.md`.
- **Banned Stocks Settings Manager (`docs/img/banned_stocks.png`)**:
  - Added dedicated interface screenshot displaying the Banned Stocks interactive chip list, manual `+ Add Symbol` input bar, and active toggle switch.
  - Embedded into `README.md` showcase table, `docs/wiki/Real-Time-Momentum-Screener.md`, and `docs/wiki/Running-Momentum-Tape.md`.
