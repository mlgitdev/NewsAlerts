# NewsAlerts v2.9.0 — Release Notes

**Release Date:** October 2026  
**Type:** Minor Release (`MINOR` — New Distribution Formats & Setup Installer)  
**Single Source of Truth:** `VERSION` (`2.9.0`)

---

## 🚀 Overview

NewsAlerts **v2.9.0** introduces the **Dual Distribution Model**, providing day traders with two distinct packaging formats:
1. **High-Performance Unpacked Application & Setup Installer**: Pre-extracted directory targeting `%LOCALAPPDATA%\Programs\NewsAlerts` with an Inno Setup installer wizard (`NewsAlerts-Setup-v2.9.0.exe`). This eliminates PyInstaller `%TEMP%` extraction and real-time antivirus interception delays, accelerating cold startup from ~2.0s down to **sub-300ms** (<0.2s warm starts).
2. **Portable Standalone Executable**: The traditional single-file binary (`NewsAlerts.exe`) for drop-in, zero-installation use cases and USB drives.

## 🛠️ Key Additions & Architectural Enhancements

### 1. Dual-Target PyInstaller Pipeline (`NewsAlerts.spec`)
- Generates both the portable single-executable (`dist/NewsAlerts.exe`) and the unpacked application bundle (`dist/NewsAlerts-App/`) simultaneously in a single 25-second build pass.

### 2. Inno Setup Windows Installer (`installer/NewsAlerts.iss`)
- Modern, lightweight installer (~13.5 MB compressed with LZMA2).
- Per-user installation into `%LOCALAPPDATA%\Programs\NewsAlerts` (no UAC / Administrator elevation required).
- Generates Start Menu (`{autoprograms}`) and Desktop shortcuts with proper application icon.
- Registers a clean uninstaller in Windows *Settings &rarr; Installed Apps*.

### 3. Build & Make Automation
- **PowerShell (`build.ps1`)**:
  - `.\build.ps1 -Task build` — Builds both portable and unpacked targets.
  - `.\build.ps1 -Task run-app` — Launches unpacked app directly from `dist\NewsAlerts-App\`.
  - `.\build.ps1 -Task install-local` — Installs directly into `%LOCALAPPDATA%\Programs\NewsAlerts` and creates desktop shortcuts.
  - `.\build.ps1 -Task installer` — Compiles Inno Setup installer via `iscc`.
- **Universal Makefile (`Makefile`)**:
  - Added targets: `run-app`, `install-local`, and `installer`.

### 4. macOS Native Application Bundle & DMG Installer
- `install.sh` automatically constructs a native macOS `~/Applications/NewsAlerts.app` bundle with Apple Silicon support, Apple `.icns` icon, and `Info.plist`, making NewsAlerts searchable in Spotlight and launchable from Launchpad and Dock.
- Release workflow generates native Apple Disk Image (`NewsAlerts-macOS-arm64.dmg`) with drag-and-drop installer into `/Applications`.

### 5. GitHub Actions CI/CD Integration (`.github/workflows/release.yml`)
- Windows release runner installs Inno Setup via Chocolatey (`choco install innosetup --no-progress`).
- Publishes official installer executable `NewsAlerts-Setup-v2.9.0.exe` alongside the portable zip `NewsAlerts-Windows-x64.zip` and native macOS DMG `NewsAlerts-macOS-arm64.dmg` in GitHub Releases.
### 6. Secrets Storage Transparency & One-Click Native Folder Launch
- Added real-time filesystem transparency in Settings &rarr; About and Settings &rarr; Backup & Sync, displaying the active resolved OS directory (`APP_DIR`) alongside an interactive **📂 Open Folder** button to launch Explorer / Finder directly.
- Clarified credential management status (`config.json` vs optional `keys.toml` override).

### 7. Universal US-Listed Stock Coverage (Fix for Foreign-Incorporated Issuers)
- Removed restrictive `country == "United States"` filter from base scanner queries. All stocks listed on major US exchanges (`NASDAQ`, `NYSE`, `AMEX`) are now fully covered regardless of corporate jurisdiction (e.g. `SAIQ`, `GCT`, `TOP`, Canadian/BVI/Cayman issuers).
- Resolves issue where valid US-listed momentum runners were omitted from screener and news custom inspection.
