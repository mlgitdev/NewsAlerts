# NewsAlerts v2.4.0 Release Notes

**Release Date:** October 19, 2026  
**Build Target:** Windows x64, macOS arm64, Linux x86_64  

---

## 🚀 Key Highlights & New Features

### 1. Unified Alert Pause & Resume (The Bell Button)
- Re-architected the topbar bell button into a unified master alert toggle.
- Clicking the bell now **both mutes audio chimes AND suspends Telegram push notifications** for both Screener new symbol alerts and Tape momentum alerts.
- Provides immediate visual status feedback:
  - **Active**: Green-tinted bell icon (`#38efb0`).
  - **Paused**: Slashed bell icon (`bellOff`) with red warning styling (`#ff6b7e`) and pulsing animation.

### 2. Interactive Rising Triangle Volume Control
- Added an interactive volume control widget featuring an SVG wedge rising from left to right.
- Visual fill with vibrant neon emerald green (`#00e676`) reflecting the exact volume level (0% to 100%) against a dark app background.
- Dynamic speaker icon state (`volHigh`, `volLow`, `volMute`).
- Native Windows WinMM waveform audio scaling via `waveOutSetVolume` and cross-platform volume control on macOS (`afplay -v`) and Linux.

### 3. Institutional Brand Identity, App Icon & Hero Graphic
- Designed an authoritative, non-AI-slop visual brand identity:
  - **Master App Icon**: Geometric golden alert bell merged with rising emerald green Japanese candlestick bars and radar alert broadcast waves.
  - **Cinematic 16:9 Hero Banner**: Candlestick breakout chart piercing resistance, radiant gold/emerald bell emblem, and live digital news wire telemetry.
- Generated multi-resolution Windows standard DIB `.ico` (`assets/icon.ico`), macOS Apple `.icns` (`assets/icon.icns`), and Linux `.png` launcher icon.
- Built-in About tab in Settings modal and empty-state intelligence banner in the News pane.

### 4. Cross-Platform Multi-OS Support
- **Windows x64**: Standalone portable single `.exe` (~14 MB) embedding the custom icon.
- **macOS arm64**: Native WebKit/Cocoa window, Apple Silicon optimization, and `install.sh`.
- **Linux x86_64**: Native WebKit2GTK window, XDG directory compliance, desktop launcher (`.desktop`), and `install.sh`.

### 5. Robust Rolling Tape Persistence
- 4-day disk-backed history retention (`tape_history.json`) preserving all HOD momentum alerts and squeeze breakouts across weekends and off-hours.
- Monotonic squeeze breakout trigger filtering: prevents redundant triggers on price pullbacks within active 5m and 10m windows.

### 6. Automated GitHub CI/CD & Governance
- PR validation bot with Conventional Commits and required section checks.
- Automated secret scanning on every push and PR to protect against credential leakage.
- Multi-OS build matrix validating Windows, macOS, and Linux builds.
- Automated release packaging and release notes distribution.
