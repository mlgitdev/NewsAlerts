# NewsAlerts v2.11.2 — Release Notes

**Release Date:** October 2026  
**Type:** Patch Release (`PATCH` — Prominent Table Imagery & Universal `make env` Targets)  
**Single Source of Truth:** `VERSION` (`2.11.2`)

---

## 🚀 Overview

NewsAlerts **v2.11.2** delivers a significant readability upgrade to documentation and developer ergonomics across platforms:
1. **Prominent Interface Showcase Tables**: Refactored the core terminal feature tables in `README.md` and `docs/SPEC.md` to prioritize large, native-resolution screenshots over cramped text, allocating 68% of the width to interface captures and 32% to capability summaries. Screenshots are now immediately readable directly on the page without requiring users to click thumbnails.
2. **Dedicated Cross-Platform `make env` Targets**: Decoupled virtual environment creation and package installation from binary builds. Developers can now run `make env` on any OS (or `make env-win`, `make env-linux`, `make env-mac`) to configure Python dependencies, while `make build` focuses strictly on compiling standalone distribution executables and packages.

---

## 🌟 Key Changes & Improvements

### 1. High-Visibility Feature Showcase Tables (Issue #63)
- Replaced Markdown pipe tables with responsive HTML `<table>` elements with fixed column percentage weighting:
  - **Interface Captures (`width="68%"` / `width="100%"` image)**: Screenshots render at full native width with high-DPI clarity, rounded borders, and subtle institutional drop shadows.
  - **Terminal Capabilities (`width="32%"` text)**: Crisp executive summaries and bullet points aligned neatly alongside the corresponding UI panel.
- Fully synchronized across both [`README.md`](../../README.md) and [`docs/SPEC.md`](../SPEC.md).

### 2. Universal & OS-Specific `make env` Targets
- **`make env`**: Universal auto-detection target. Inspects the host OS (`Windows`, `Linux`, `macOS`), checks or creates the local `.venv`, upgrades `pip`, and installs all dependencies from `requirements.txt`.
- **`make env-win`**: Dedicated Windows target invoking PowerShell automation.
- **`make env-linux`**: Dedicated Linux target preparing `python3 -m venv` and installing packages.
- **`make env-mac`**: Dedicated macOS target preparing Apple Silicon Python virtual environments.
- **`.\build.ps1 -Task env`**: Added native PowerShell environment preparation task for Windows developers who do not use `make`.

### 3. Decoupled `make build` Workflow
- Refactored `make build` to strictly focus on binary compilation (`PyInstaller` standalone `.exe` / `.app` / dual package directories) without performing background dependency installations.
