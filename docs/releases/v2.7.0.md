# NewsAlerts v2.7.0 Release Notes

**Release Date:** 2026-10-21  
**Release Tag:** `v2.7.0`  
**SemVer Specification:** `2.7.0` (Major: 2, Minor: 7, Patch: 0)  

---

## 🚀 Overview

NewsAlerts `v2.7.0` is a feature release introducing three major capabilities for active day traders:
1. **Custom Symbol Search in News Wire**: Immediate quote, catalyst headlines, Benzinga wire, and Alpaca short borrow locate inspection for any US common equity (AMEX, NASDAQ, NYSE) with pinned quick-access watchlist chips.
2. **Interactive Strategy Builder**: Dynamic creation (`+ Add Strategy`), trigger type customization (`New HOD`, `52w Breakout`, `Squeeze`), family classification, and deletion directly within the terminal Settings.
3. **Backup / Import & Export Sync**: Dedicated backup center for full terminal configuration backups and strategy definition sharing via standard `.json` format, with schema validation and one-click factory reset.

---

### 🌟 Key Enhancements

### 1. Custom US Equity Symbol Inspection (`News Wire`)
- **Direct Symbol Search Bar**: Added sticky institutional search bar at the top of the News pane with autofocus and Enter-to-inspect shortcuts.
- **US Market Scoping**: Queries are strictly resolved against US primary equities across NASDAQ, NYSE, and AMEX via TradingView scanner and Alpaca Market Data.
- **Full Metadata Header**: Immediately renders company logo, live session quote, change %, float size, bid/ask spread, session VWAP, and color-coded short borrow locates (`ETB`, `HTB`, `NO BORROW`).
- **Interactive Quick-Access Chips**: Inspected tickers are stored in `news.custom_symbols` and displayed as clickable chips (`[ SMCI × ] [ NVDA × ] [ AAPL × ]`) for instant switching, with `×` remove buttons.

### 2. Interactive Tape Strategy Builder
- **Dynamic Creation (`+ Add Strategy`)**: Add unlimited customized momentum strategies with custom float ranges, relative volume thresholds, price filters, 52-week breakout ratios, and surge velocity windows.
- **Trigger Type Selector**: Switch between `New HOD` (session high prints), `52w Breakout` (52-week high penetrations), and `Up X% in N min` (momentum squeezes).
- **Family Classification**: Categorize strategies into `Low Float`, `Medium Float`, `Large Cap`, `Squeeze`, or `Custom`.
- **Strategy Deletion (`🗑️`)**: Instantly remove unwanted strategies. Deletions are tracked in `tape.deleted_strategies` so default factory presets do not resurrect upon application restart.
- **Inline Import & Export**: One-click `💾 Export` and `📂 Import` buttons directly above the strategies table for rapid preset loading.

### 3. Dedicated Backup / Import & Export Tab
- **Full Configuration Backup (`.json`)**: Export complete terminal state—including screeners, audio chime paths, volume levels, hotkeys, universe filters, and strategy definitions—for safe disaster recovery or cross-machine migration.
- **Strategies Sync (`.json`)**: Export or import strategy definitions independently to exchange tactical presets with community trading groups.
- **Intelligent Schema Validation**: Validates JSON file structures, prevents corrupt configurations, and provides clear error notifications.
- **Factory Defaults Reset**: One-click restore button allowing traders to revert all settings and strategies back to clean factory defaults with confirmation safeguards.
