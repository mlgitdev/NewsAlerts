# NewsAlerts v2.5.0 Release Notes

**Release Date:** 2026-10-20  
**Release Tag:** `v2.5.0`  
**SemVer Specification:** `2.5.0` (Major: 2, Minor: 5, Patch: 0)  

---

## 🚀 Overview

NewsAlerts `v2.5.0` is a minor release introducing the **Customizable Keyboard Shortcuts & Hotkey Configuration** tab in the Settings modal. Traders can now fully customize, rebind, and record personalized keyboard shortcuts to suit their execution flow, with institutional defaults preserved.

### 🌟 Key Features & Enhancements

1. **Dedicated Hotkeys Configuration Tab**:
   - Added a new "Hotkeys" tab in the Settings modal (`web/index.html` and `web/js/settings.js`).
   - Interactive keypress capture: click on any shortcut input and press the desired key (e.g., `M`, `T`, `Space`, `Enter`, `F5`, numbers, or letters) to bind it immediately.
   - Built-in "↺ Reset Defaults" button to instantly restore institutional trading defaults.
   - Distinct reserved navigation display for table row browsing (`▲ / ▼`).
   - Non-intrusive focus guard: hotkeys automatically yield when typing inside text boxes or search inputs.

2. **Institutional Default Hotkeys**:
   - `M`: Master Mute / Pause Alerts (toggles sound and Telegram notifications).
   - `T`: Pop-Out Running Tape (opens detached floating momentum tape window).
   - `Space`: Pause / Resume Tape Stream (holds incoming alert stream or resumes flow).
   - `S`: Open Settings Modal.
   - `R`: Force Refresh (re-scans momentum screener and news headline feed).
   - `Escape`: Close Modals / Drawers / Catalyst Stories.
   - `Enter`: Focus / Expand First Catalyst News Story.
   - `1` – `5`: Instant switch between screener preset tabs.
   - `ArrowUp` / `ArrowDown`: Screener table row navigation.

3. **Dynamic Hotkey Matching & Synchronization**:
   - Updated main terminal keydown listener in `web/js/app.js` to dynamically query configured hotkeys from `App.config.hotkeys`.
   - Updated detached tape listener in `web/js/tape.js` to query configured `pause_tape` hotkey from `App.config.hotkeys.pause_tape`.
   - Normalized single-character keys to case-insensitive uppercase and mapped `" "` to `"Space"`.

4. **Multi-OS Configuration Persistence**:
   - Defined `DEFAULT_HOTKEYS` in `app/config.py` and merged with `DEFAULT_CONFIG["hotkeys"]`.
   - Automatically persisted to `%APPDATA%\NewsAlerts\config.json` (Windows), `~/.newsalerts/config.json`, or system app directory.
   - Added unit test suite in `tests/test_config.py` verifying hotkey provisioning, customization, and reload persistence.

5. **Updated Documentation**:
   - Updated `docs/wiki/Keyboard-Shortcuts-&-Hotkeys.md` documenting hotkey customization in Settings.
   - Updated `docs/CONFIGURATION.md` with the new `"hotkeys"` configuration schema.
