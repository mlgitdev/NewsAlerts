# NewsAlerts v2.11.1 — Release Notes

**Release Date:** October 2026  
**Type:** Patch Release (`PATCH` — Toggleable Opt-Out for BamSEC Filings Visibility & Utilization)  
**Single Source of Truth:** `VERSION` (`2.11.1`)

---

## 🚀 Overview

NewsAlerts **v2.11.1** introduces an institutional opt-out configuration capability for the **BamSEC SEC Filings** module. While enabled and opt-in by default for rapid catalyst diligence, traders who prefer a streamlined, pure Benzinga/PR wire feed can now completely disable BamSEC with a single setting. When disabled, all BamSEC visual elements are cleanly unmounted from the DOM, and all underlying background scraper calls and timers are halted.

---

## 🌟 Key New Features & Capabilities

### 1. Toggleable Opt-Out Setting (Issue #61)
- **Settings &rarr; General Toggle**:
  - Added an intuitive checkbox: **"Enable BamSEC Filings"** (*Opt-in or fully remove BamSEC filings, badges, and background network calls across the terminal*).
  - Config key `news.bamsec_enabled` defaults to `true` (opt-in).
  - When unchecked, dependent settings (such as `Display Layout Mode`) are automatically disabled and dimmed.

### 2. Complete DOM & UI Cleanliness
- When opted out (`news.bamsec_enabled = false`):
  - The `[📑 BamSEC ↗]` external launch button next to TradingView chart button is completely omitted.
  - The `📑 N SEC` count badge next to the borrow tag is completely omitted.
  - The collapsible top drawer accordion and the sub-tabs navigation are completely removed.
  - The layout mode switch button (`⊞ Tabs View` / `⊟ Drawer View`) is omitted.
  - The News pane renders purely as an unencumbered wire news stream.

### 3. Immediate Network & Scraper Call Suppression
- Backend `Api.get_bamsec()` evaluates `news.bamsec_enabled`. When disabled, it immediately returns `{"disabled": True}` without initializing scraper sessions or performing HTTP requests to BamSEC.
- Frontend polling timers in `News.select()` and ticker change handlers bypass BamSEC loading entirely when disabled.

### 4. Reactive Dynamic Reconfiguration
- Saving settings immediately invokes `News.onConfigChanged()`:
  - Toggling BamSEC off clears cached data, unmounts drawer/tabs, and re-renders the header cleanly without requiring an application restart.
  - Toggling BamSEC back on restores the drawer/tabs and immediately fetches filings for the active ticker.
