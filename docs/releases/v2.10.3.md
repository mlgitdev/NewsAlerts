# NewsAlerts v2.10.3 — Release Notes

**Release Date:** October 2026  
**Type:** Patch Release (`PATCH` — Ban Symbol API Routes & Optimistic UI Synchronization)  
**Single Source of Truth:** `VERSION` (`2.10.3`)

---

## 🚀 Overview

NewsAlerts **v2.10.3** fixes an unhandled TypeError during inline 🚫 symbol blacklisting on the Running Momentum Tape and Screener grid caused by missing server API routes. In addition, UI synchronization is now executed optimistically and synchronously so row buttons, topbar badges, and table filters instantly reflect banned/unbanned state without lag or freezing.

---

## 🛠️ Key Bug Fixes & Enhancements

### 1. Ban & Filter Banned API Route Registration (Issue #54)
- **Server Routes (`app/server.py`)**:
  - Registered `/api/ban_symbol` (`POST`), `/api/unban_symbol` (`POST`), and `/api/toggle_filter_banned` (`POST`) endpoints routing directly to `api.ban_symbol()`, `api.unban_symbol()`, and `api.toggle_filter_banned()`.
- **Client API Mapping (`web/js/util.js`)**:
  - Implemented `ban_symbol(symbol)`, `unban_symbol(symbol)`, and `toggle_filter_banned(enabled)` helpers in `_api`.
  - Resolved `TypeError: App.api().ban_symbol is not a function` which previously aborted execution and prevented downstream UI updates.

### 2. Optimistic & Resilient UI Synchronization (`web/js/app.js`)
- **Instant UI Refresh**:
  - When clicking 🚫 on Tape or Screener, `App.config.banned_symbols` is updated in memory and UI renderers (`updateFilterBannedButton()`, `Screener.renderTable()`, `Tape.renderAll()`, `News.renderHead()`) are executed immediately before network dispatch.
  - Buttons immediately reflect the red `.is-banned` active state (or the row is hidden if filter is active), and topbar counter increments instantly.
- **Safe Network Dispatch**:
  - Backend API invocations (`App.api().ban_symbol()`, `App.api().unban_symbol()`, `App.api().toggle_filter_banned()`) are wrapped in `try...catch` blocks to protect client responsiveness against temporary network glitches.

### 3. Tape Alert Count Filter (`web/js/tape.js`)
- **Banned Event Suppression in Header**:
  - Updated `Tape.updateNewBtn()` to filter out banned symbols when calculating visible alert count (`vis`) while `filter_banned` is active.
