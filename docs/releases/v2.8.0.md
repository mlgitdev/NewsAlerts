### 🌟 Key Features & Improvements

### 1. Watchlist Selector Bar (`#watchlist-bar`)
- **Positioned Directly Above News Pane**: Accessible and visible at all times right above the catalyst news wire.
- **Dynamic Cloud List Retrieval**: Queries TradingView custom watchlists via `https://www.tradingview.com/api/v1/symbols_list/custom/` using authenticated session cookies.
- **Instant Synchronization**: Includes a manual sync/refresh button (`🔄`) to pull newly created watchlists from TradingView cloud without restarting the app.
- **Connection Status Badge**: Clear visual indicator showing `TV Cloud` (blue) when connected to TradingView cloud, or `Local` (yellow) when offline/unauthenticated.

### 2. 1-Click Quick-Add (`+`) Buttons
- **Ubiquitous Symbol Adding**: Added dedicated `+` quick-add buttons beside stock tickers in:
  1. **Screener Table**: Beside symbol badge in the main screener rows.
  2. **Running Momentum Tape**: Directly next to the symbol link in each momentum event row.
  3. **News Pane Header**: Next to the inspected stock symbol in the catalyst news header.
- **Automatic Exchange Formatting**: Resolves bare symbols (e.g., `SMCI`) into institutional `EXCHANGE:TICKER` standard (e.g., `NASDAQ:SMCI`) before appending to TradingView lists.

### 3. Visual Flickering Feedback & Error Handling
- **Success & Already Exists**: Clicking `+` triggers an instant, non-disruptive silent green flickering animation (`flicker-green`) for 3 seconds, transforming into `✓`. No modal popups or disruptive alerts.
- **Failure**: On expired session or network error, triggers a 3-second red flickering animation (`flicker-red`) transforming into `✕`, accompanied by an error toast popup.
- **Offline / Local Fallback**: When unauthenticated, symbols are saved to persistent local watchlists in `config.json`.
